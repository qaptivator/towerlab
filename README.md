# TowerLab

Local-first tower kit converter and Roblox DOM inspector powered by Rust, WebAssembly, and Nuxt.

TowerLab is a browser-based workbench for inspecting Roblox .rbxm, .rbxmx, .rbxl, and .rbxlx files and migrating tower kits across formats and versions. Powered by Rojo's rbx-dom compiled to WebAssembly alongside a typed TypeScript DOM layer and a minimal Nuxt interface, it handles tree exploration and kit conversion passes locally on your device without uploading files to external servers.
